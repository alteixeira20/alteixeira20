## Open-source maintenance

### [Odysseus](https://github.com/odysseus-dev/odysseus) | Core maintainer

Odysseus is a self-hosted AI workspace for chat, agents, research, documents, and local model workflows. My contributions include architecture, security boundaries, regression testing, reliability, review practices, and maintainer coordination.

Examples of merged work:

- **Security and authorization:** [behavioral tests for admin access boundaries](https://github.com/odysseus-dev/odysseus/pull/6965).
- **Architecture:** [frontend source ownership and architecture gates](https://github.com/odysseus-dev/odysseus/pull/6701).
- **Test reliability:** [tests that detect false-positive passes](https://github.com/odysseus-dev/odysseus/pull/6978).
- **Open-source governance:** [public maintainer handbook and review playbook](https://github.com/odysseus-dev/odysseus/pull/6736).

My engineering approach is **design → build → test → audit → iterate → ship**. AI supports research, implementation, and review, but reproducible validation and independent verification remain essential.
