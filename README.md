# Alexandre Teixeira

**AI-Augmented Product Engineer · Lead Maintainer at [Odysseus](https://github.com/odysseus-dev/odysseus)**  
> Software Architecture · AI Agent Systems · Monolith Decomposition · Test Automation · Application Security

I design, build, modernize, and maintain software end to end. My work spans architecture, implementation, automated testing, security review, infrastructure, deployment, and open-source maintenance.

A major part of my current work is **decomposing tightly coupled systems into modular, maintainable architectures**: identifying real component boundaries, preserving behavior, consolidating duplicate execution paths, defining explicit contracts, and making changes independently testable. I care about what runs in production, not just what looks clean in a diagram.

AI is central to my engineering workflow. I use coding agents for research, implementation, verification, and coordination, with deliberate attention to context, reproducibility, tool overhead, and independent review. **Agent output is a candidate, not evidence of correctness.**

## What I focus on

- **Architecture and modernization:** breaking down monoliths, reducing coupling, establishing cohesive modules, clear ownership, stable interfaces, and migration paths that preserve existing functionality.
- **AI agent infrastructure:** building and refining agent harnesses, execution lifecycles, model/provider integration, tool and MCP interfaces, durable state, recovery boundaries, and permission-aware automation.
- **Verification and security:** designing regression suites, reproducible test environments, fault-injection checks, integration validation, security reviews, and evidence-based release gates.
- **Engineering leadership:** maintaining open-source codebases, reviewing PRs and architecture changes, coordinating parallel development, resolving correctness issues, and turning complex technical work into deliverable products.

> [!IMPORTANT]
> I enjoy getting into complex codebases, understanding how everything fits together, and making them easier to maintain and extend. A lot of my work involves untangling tightly coupled components, defining clearer responsibilities, and building automated tests that expose failures before they become bigger problems.
